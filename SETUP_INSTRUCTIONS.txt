## ⚡ 5-MINUTE QUICK START

### 1. Setup Database (1 minute)
- Open: http://localhost/phpmyadmin
- Create database: `rks_student_system`
- Go to SQL tab
- Paste content from: `d:\xampp\htdocs\final\config\database.sql`
- Click Execute

### 2. Access Application (1 minute)
- Go to: http://localhost/final/
- Click Login

### 3. Login as Admin (immediate)
```
URL: http://localhost/final/
Username: admin
Password: admin123
```

### 4. Create Staff Accounts (2 minutes)
- In Admin Panel: Dashboard → Users → Add User
- Create accounts for: Secretary, Principal, HOD, Class Teachers

### 5. Students Register Themselves (1 minute per student)
- Students go to: http://localhost/final/register.php
- Fill registration form
- Login with their credentials

## 🚀 CREATING NEW USERS (ADMIN ONLY)

### To Add Secretary:
1. Admin Dashboard → Users
2. Click Add User
3. Fill:
   - Username: secretary
   - Password: any strong password
   - Email: secretary@rkmshome.edu
   - Role: Secretary
4. Click Add User

### To Add Principal:
1. Admin Dashboard → Users
2. Click Add User
3. Fill:
   - Username: principal
   - Password: any strong password
   - Email: principal@rkmshome.edu
   - Role: Principal
4. Click Add User

### To Add HOD (For each department):
1. Admin Dashboard → Users
2. Click Add User
3. For DME:
   - Username: hod_dme
   - Password: strong_password
   - Email: hod@dme.rkmshome.edu
   - Role: HOD
   - Department: DME
4. Repeat for DAE and DCE

### To Add Class Teachers:
1. Admin Dashboard → Users
2. Click Add User
3. Fill:
   - Username: teacher_name
   - Password: strong_password
   - Email: teacher@rkmshome.edu
   - Role: Class Teacher
   - Department: (DME/DAE/DCE)
4. Click Add User

## 🆘 NEED HELP?

### Common Issues

**Q: Can't login?**
A: Check if MySQL and Apache are running in XAMPP

**Q: Database not found?**
A: Ensure you imported the SQL file into phpMyAdmin

**Q: Student registration fails?**
A: Check department is selected and username doesn't already exist

**Q: Can't upload profile picture?**
A: Verify `/uploads/` folder has write permissions

**Q: Messages not sending?**
A: Check if receiver user exists in system
